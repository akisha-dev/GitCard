# GitCard 

Turn any GitHub profile into a beautiful, shareable card.

## Features
-  Search any GitHub username
-  View stats, top languages, and recent repos  
-  Download your card as PNG
-  Direct links to repos and profiles

## Built With
React · Tailwind CSS · Vite · GitHub REST API · html2canvas-pro
